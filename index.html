Google Play Store Analytics

Internship Data Analytics Project

📌 Project Overview

This project was developed as part of internship training using the Google Play Store dataset. The project analyzes Android applications and generates meaningful insights about ratings, reviews, installs, categories, app types, revenue and growth trends.

🎯 Objectives

  • Clean and preprocess Google Play Store data.
  • Analyze application categories and performance.
  • Analyze ratings, reviews and installations.
  • Compare free and paid applications.
  • Analyze revenue and growth trends.
  • Create informative data visualizations.
  • Implement internship tasks using the same training dataset.

🛠 Technologies Used

  • Python
  • Pandas
  • NumPy
  • Plotly
  • Matplotlib
  • Jupyter Notebook

📊 Analytics & Visualizations

  • Bar Charts
  • Line Charts
  • Dual-Axis Analysis
  • Stacked Area Charts
  • Bubble Charts
  • Choropleth Maps
  • Category Rating and Review Analysis
  • Free vs Paid Application Analysis
